## 🔭 Featured projects

### 🪑 [VisioLens — Object Detection for Interiors](https://github.com/Huzaifaarif123/Object-Detection-Project-)
Upload a room photo and get **contour outlines** — not just bounding boxes — around chairs,
tables and carpets. **Grounding DINO** finds objects from plain-text prompts, **SAM** turns each
box into a mask, and the polygons are drawn over the image in the browser. Prompt-driven, so
detecting something new means editing a list, not retraining a model.

`Python` · `Grounding DINO` · `SAM` · `Flask` · `React` · `Docker`
→ **[Live demo](https://object-detection-project-three.vercel.app)**

### 📐 [AI Layout Generator (Final Year Project)](https://github.com/Huzaifaarif123/AI-Model-FYP)
A Flask service that predicts space ratios with a trained scikit-learn model, builds a floor
layout from them, validates it against geometric constraints, and renders the result as SVG.
Clean separation between `layout_engine`, `constraints` and `renderer`.

`Python` · `Flask` · `scikit-learn` · `SVG`

### 🐦 [Kairo](https://github.com/Huzaifaarif123/Kairo-)
An AI-assisted job-search workspace built on the open-source
[ai-job-search](https://github.com/MadsLorentzen/ai-job-search) framework — job scraping,
CV tailoring, cover letters and company research, with a web dashboard on top.

`JavaScript` · `TypeScript` · `Python`
→ **[Live demo](https://kairo-delta-nine.vercel.app)**

### 📊 [AI/ML Training Notebooks — NETSOL](https://github.com/Huzaifaarif123/NETSOL-Tasks-AI-ML-)
Three weeks of hands-on data science work: Python fundamentals, probability, data structures,
visualization, hypothesis testing, Naive Bayes classification and exploratory data analysis.

`Jupyter Notebook` · `pandas` · `matplotlib`

### 🧾 [KMD Middle East](https://github.com/Huzaifaarif123/KMD-Middle-East-)
A React site for an accounting and tax consultancy in the Middle East — service pages,
responsive layout, deployed on Vercel.

`React` · `CSS`
→ **[Live site](https://kmd-middle-east.vercel.app)**

### 🩸 [Blood Donor System](https://github.com/Huzaifaarif123/Blood-Donor-System)
A web-based donor–recipient matching system with three roles: **Admin**, **Donor** and
**Recipient**, built to keep blood supply moving efficiently.
